# Weekly review

A short, repeatable pass over the work. Use it with [[Dashboard]]: the dashboard
shows the shape, this note says what to do about it, and the daily notes record
what you found.

## Order

1. Clear anything **overdue** first, or move its date on purpose.
2. Read the **blocked** list and chase exactly one thing per blocker.
3. Check each project has a next move that fits this week.
4. Close what is actually finished, rather than leaving it in progress.
5. Write down the one decision you are avoiding.

## When something is stuck

| Condition | Action |
| --- | --- |
| Blocked more than a week | Escalate, or drop it and say so |
| Project past its target | Pick a new date or close the project |
| Task nobody can name an owner for | It is not a task yet |
| Two people asked the same question | It belongs in the help centre |
