# Wikilinks and tags

Two lightweight conventions turn a pile of notes into a connected workspace.

## Wikilinks

Write `[[Note name]]` to link to another note. For example, this links back to [[getting-started]] and over to [[guides/markdown-basics]].

Switch to the **Graph** tab in the sidebar to see every note as a node, with a line drawn for each wikilink. Click a node to open that note.

<Callout type="info" title="How matching works">
A wikilink matches a note by its name or its path, without the extension. When two notes share a name, the one in the linking note's folder wins, then the one closest to the workspace root, then the first by path. A path such as projects/Recovery reaches only that note. Typing `[[` in the source editor offers every note and writes the shortest link that reaches it, and a note's `aliases:` are names it can be linked by too.
</Callout>

So to reach the note in the projects section, link to [[projects/Recovery]].

## Tags

Write a `#tag` anywhere in a note. Neuron collects every tag into the filter at the bottom of the sidebar — click one to narrow the list to notes that mention it.

This note carries a couple:

#guide #links #organization
