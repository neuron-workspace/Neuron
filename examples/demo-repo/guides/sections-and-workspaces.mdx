# Sections and workspaces

## Sections are folders

A section is a folder of notes. Create one from the `+` button in the sidebar (the **Section** tab), or hover a folder and use its `+` to add a note inside it. Folders collapse and expand in the tree.

This workspace has a few sections to look at:

- **guides/** — the note you are reading, and its neighbours
- **projects/** — one note per project, e.g. [[projects/Recovery]]
- **daily/** — a date-based journal, e.g. [[daily/2026-06-19]]
- **properties/** — frontmatter examples

One folder is not a section at all. **Snake/** holds a `neuron.app.json`, so the
whole folder renders as a single app instead of a list of files.

You can nest a section inside another, and a note can live at the workspace root or any depth.

## Workspaces

The whole folder you opened is a **workspace**. Use the switcher in the title bar to:

- **Open folder** — point Neuron at any existing folder of Markdown.
- **Create workspace** — start a fresh one with a welcome note.
- **Recent** — jump back to a workspace you used before.

<Callout type="info" title="Cloud is just a folder">
Put a workspace inside OneDrive, Dropbox, or iCloud and it syncs like any other folder — Neuron marks it with a small cloud icon. No special setup.
</Callout>
